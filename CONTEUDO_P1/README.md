# 📘 Conteúdo P1 — Funções, vetores e matrizes

Nesta parte dos estudos, os exercícios começam com operações simples e avançam para programas que lidam com conjuntos de informações. O objetivo é praticar **funções, laços de repetição, vetores, matrizes e organização do código em arquivos de cabeçalho**.

## 📂 Exercícios disponíveis

| Pasta | Assunto |
|---|---|
| [Programa 1](programa-1/README.md) | Sequência de cálculos com funções e valores retornados. |
| [Programa 2](programa-2/README.md) | Tabuadas com laços aninhados e cálculo do cubo dos produtos. |
| [Programa 3](programa-3/README.md) | Cadastro, consulta e movimentação de um pequeno estoque. |
| [Programa 3 com cabeçalho](programa-3-biblioteca/README.md) | Outra organização do controle de estoque, com rotinas em `funcoes.h`. |
| [Programa 4](programa-4-biblioteca/README.md) | Declaração de variáveis e funções em arquivos `.h`. |
| [Programa 5](programa-5-biblioteca/README.md) | Calculadora com operações separadas por cabeçalhos. |
| [Programa 6](programa-6-biblioteca/README.md) | Simulação de um ônibus com mapa de poltronas em matriz. |

## 🧩 O que esse conjunto permite estudar

Os primeiros programas mostram como passar valores para funções, receber resultados e repetir operações. Nos exercícios de estoque, os **vetores paralelos** mantêm nome, código, preço e quantidade de cada produto associados à mesma posição. Já a simulação do ônibus utiliza uma **matriz** para representar fileiras e poltronas.

As versões com cabeçalhos ajudam a observar como um programa pode ser dividido em arquivos menores, mantendo a função principal separada de outras rotinas.

A pasta também inclui configurações do editor em [`.vscode/`](.vscode/tasks.json).
