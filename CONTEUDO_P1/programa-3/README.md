# 📦 Programa 3 — Controle de estoque

Um exercício de terminal que reúne **cadastro de produtos, consulta de estoque e simulação de compras**. O programa trabalha com até três produtos e utiliza vetores para relacionar as informações de cada um.

## 🛒 Recursos do exercício

- Cadastro com **nome, código, preço e quantidade** disponível.
- Consulta de produtos pelo código.
- Exibição da tabela de itens cadastrados.
- Registro de compras com atualização das quantidades em estoque.
- Apresentação de um resumo com o valor total da compra.

Os dados são mantidos em **vetores paralelos**: a mesma posição representa o mesmo produto nos conjuntos de nomes, códigos, preços e quantidades. Esse modelo ajuda a estudar o acesso e a atualização de informações durante a execução.
