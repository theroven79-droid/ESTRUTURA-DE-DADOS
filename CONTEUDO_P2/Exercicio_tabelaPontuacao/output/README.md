## 📌 Conteúdo da pasta

Este diretório contém o **executável para Windows** do projeto de classificação de equipes. A entrada de dados, os critérios de ordenação e as rotinas de exibição estão documentados na pasta imediatamente superior.

| Arquivo | Descrição |
|---|---|
| [`main.exe`](main.exe) | Executável armazenado em `output`. |
| [`../main.cpp`](../main.cpp) | Arquivo principal do código-fonte. |
| [`../inserir.txt`](../inserir.txt) | Dados de exemplo com nomes de times, gols e pontuação. |

## 🔎 Relação com o projeto

O programa organiza 12 equipes conforme a pontuação e, em caso de empate, a quantidade de gols. Ele utiliza funções distribuídas em arquivos de cabeçalho, disponíveis na pasta superior.

Para compreender a lógica de classificação e as limitações dos comandos de terminal, consulte o [relatório do projeto](../README.md). A presença do executável não representa uma validação automática do programa.
